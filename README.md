# Asset Checkout Manager

## Overview

Asset Checkout Manager is a Python command-line application for managing organizational assets. It allows administrators to register assets, assign them to employees, process returns, mark lost assets, and generate inventory summaries.

---

## Features

- Add New Assets
- Checkout Assets to Employees
- Return Checked-Out Assets
- Mark Assets as Lost
- View Asset Inventory
- Track Asset Assignment
- Asset History
- Summary Dashboard
- Interactive Menu
